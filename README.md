# BibleDial

A mobile-first Bible verse picker that builds shareable [bible.com](https://www.bible.com) deep links. Tap a book, dial in chapter and verse on the on-screen numpad, then share, copy, or open.

**Stack:** Nuxt 4 · Nuxt UI 3 · Tailwind CSS v4 · `@nuxtjs/i18n` (en / zh-Hant / th).

## Setup

```bash
npm install
```

## Development

```bash
npm run dev        # http://localhost:3000
npm run dev -- --host    # expose on LAN for real-device testing
```

## Production

```bash
npm run build
npm run preview
```

## Other

```bash
npm run lint        # eslint .
npm run typecheck   # nuxt typecheck
```
